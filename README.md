# Constantino IT Responsive Website (AngularJS 1.x)

A modern, **responsive single-page website** built with **AngularJS 1.x** showcasing Constantino IT’s services — Home, About Us, Services and Contact.  

The site is fully deployed and accessible live via GitHub Pages:  
👉 https://ademirconstantino.github.io/cit-angular-1x/#/

---

## 🚀 Live Demo

🔗 https://ademirconstantino.github.io/cit-angular-1x/#/

---

## 📌 Features

- Built using **AngularJS 1.x** (classic Angular framework).  
- Fully **responsive layout** across screen sizes (mobile → desktop).  
- Client-side routing (SPA navigation without reloads).  
- Structured sections: Home, About Us, Services, Contact.  
- Designed with clean HTML, CSS and JavaScript.
